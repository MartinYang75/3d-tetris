# 3D 俄罗斯方块 (3D Tetris)

🎮 **在线体验地址**：[https://tetris-3d-martiny.ai.studio](https://tetris-3d-martiny.ai.studio)

一款基于 WebGL / Three.js 构建的经典三维空间俄罗斯方块小游戏。支持自由 3D 视角旋转、视角自适应方向控制、实时高度俯视雷达与 Web Audio 合成音效。

---

## 🕹️ 操作说明 (Controls)

游戏支持全向视角联动控制，按键方向将**始终跟随当前屏幕视角**，无需担心视线旋转后操作颠倒。

### 1. 移动与下落 (Movement)
* **W**：向当前视角**深处 / 前方**平移
* **S**：向当前视角**近处 / 后方**平移
* **A**：向当前视角**左侧**平移
* **D**：向当前视角**右侧**平移
* **↓ (方向下键)**：缓慢下移一格
* **Space (空格键)**：快速硬落底 (Hard Drop)

### 2. 三维旋转 (3D Rotation)
* **R 键**：前后翻转 (Pitch)
* **T 键**：水平转向 (Yaw)
* **F 键**：侧向翻滚 (Roll)

### 3. 视角控制 (Camera)
* **鼠标左键拖拽**：360° 自由旋转 3D 观察视角
* **鼠标滚轮**：视角缩放 (Zoom In / Out)

---

## ✨ 核心特性

* **视角自适应控制**：按键方向动态跟随观察视线，符合人体工学直觉。
* **实时俯视雷达**：右上角动态雷达与视角同步，实时显示各网格落定方块的堆叠最高层数。
* **多底面尺寸选择**：支持 `5×5`、`7×7`、`9×9` 三种底面尺寸切换。
* **练习模式**：开启后方块暂停自动下落，适合新手自由旋转观察与调整策略。
* **内置芯片音效**：使用原生 Web Audio API 算法合成，支持顶部一键静音/开启。
